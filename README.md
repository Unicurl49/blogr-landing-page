## Overview

### The Challenge

Users should be able to:

- View the optimal layout for the site depending on their device screen size
- See hover states for all interactive elements on the page
- Toggle the mobile navigation menu open and closed
- Open and close individual dropdown menus in the navigation

## Features

- Fully responsive across mobile, tablet, and desktop
- Working hamburger menu for mobile navigation
- Three dropdown menus in the desktop navigation (Product, Company, Connect)
- Keyboard accessible (Escape key closes menus)
- Closes menus when clicking outside
- Hover states on all interactive elements
- CSS-drawn illustrations (no external image dependencies)
- Clean, commented code throughout
